# Purchases TO-DO

Uma forma simples e prática de organizar suas compras.

## Sobre o projeto

O Purchases TO-DO é um aplicativo mobile criado para facilitar a organização da lista de compras do dia a dia. Com uma proposta objetiva e intuitiva, ele ajuda a visualizar o que precisa ser comprado e manter tudo sob controle durante a rotina.

Este projeto foi desenvolvido durante a formação em React Native da Rocketseat, com foco na construção de uma base sólida nos principais fundamentos do desenvolvimento de aplicativos mobile.

## Principais recursos

- Organização prática dos itens da lista de compras;
- Visualização clara das tarefas e prioridades;
- Experiência simples, direta e fácil de usar;
- Aplicativo pensado para acompanhar diferentes momentos da rotina.

## Tecnologias

- React Native
- Expo
- TypeScript
- React

## Como executar

Instale as dependências do projeto:

```bash
yarn install
```

Inicie o aplicativo:

```bash
yarn start
```

Também é possível executar diretamente em uma plataforma específica:

```bash
yarn android
yarn ios
yarn web
```

## Formação

Projeto desenvolvido como parte da formação em React Native da [Rocketseat](https://www.rocketseat.com.br/), com o objetivo de aplicar os fundamentos da tecnologia na criação de uma experiência mobile funcional e acessível.
